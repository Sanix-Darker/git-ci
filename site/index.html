git-ci

Run CI before you push.

A local runner for GitHub Actions and GitLab CI.

source docs

Install

git clone https://github.com/sanix-darker/git-ci.git
cd git-ci && make install

Requires Go 1.24 or newer.

Use

gci ls
gci validate --strict
gci run --job test --docker

List jobs. Validate a workflow. Run one locally.

Works with

GitHub Actions · GitLab CI · Bash · Docker · Podman
